# CoalWash on Antigravity (AG 2.0) — adapter facts

> Status: **wired — built + hermetically tested against the AG 2.0 v2.3.1 primary hook spec (antigravity.google/docs/hooks, fetched 2026-07-23; corroborated against the installed build's own docs + binary — the pilot-era `additionalContext` key is a dead letter there); NOT yet validated on a live AG session.** Engine executability is OPEN, not assumed: a 2026-07-16 clean test found both wire locations present-but-inert, but that was an OLDER build — the current build (~07-20) documents both wires live with an automatic loader (no enable flag). Live validation therefore MUST start with an engine-liveness canary before judging this adapter (see `platform-configs/VALIDATION-AG.md`). CC (`platform-cc.md`) stays the only validated platform.

## Wiring

- **Adapter:** `hooks/coalwash-ag.js` — a thin transport shim over the SAME `hooks/coalwash-conductor.js` handlers (one implementation; only the payload normalize + emit channels differ). Phoenix-13 identical: fail-silent, zero-dep, no network, no spawn.
- **Template:** `platform-configs/hooks.json` → copy to `<workspace>/.agents/hooks.json` (project) or `~/.gemini/config/hooks.json` (global), replace `__COALWASH_DIR__` with the install dir (a global file-copy install: `~/.gemini/config/skills/coalwash` — copy the whole plugin tree; the adapter imports `../scripts/lib`). Both locations are the current documented customization dirs.
- **Event arg rides argv** (`node coalwash-ag.js <Event>`): AG's stdin carries no event name.
- **Emit contract (per the v2.3.1 spec):** every registered event answers exactly one JSON line — PreInvocation `{}` or `{"injectSteps":[{"ephemeralMessage":"…"}]}` · Stop `{"decision":"allow"}` or `{"decision":"continue","reason":"…"}` · PreToolUse `{"decision":"ask"}` always. The pilot-era `{additionalContext}` key is GONE from the spec and is not emitted.

## Event mapping (AG has 5 events; SessionStart never fires there)

| CC surface | AG transport | Semantics kept |
|---|---|---|
| SessionStart gauge | **first `PreInvocation`** of a conversation, guarded by an atomic-create tmp marker (`coalwash-ag-gauge-<hash(conversationId)>.marker`) — PreInvocation fires per MODEL CALL, the marker makes the gauge once-per-conversation; later calls exit at one `existsSync` | measurement-only, silent; crossings armed identically; the writeguard sweep keeps this conversation's snapshots |
| Stop delivery (CC `{decision:'block'}`) | `Stop` → `{"decision":"continue","reason":<the same directive>}` — reason lands as a **system message** and the loop runs one more turn: a real enforcement analogue, no longer an advisory degrade | once-per-crossing + consume-at-emission unchanged; loop belt = consume-at-emission (net 1) + a per-conversation reason-hash note that turns an IDENTICAL re-emission into `allow` (net 2, covers a failed state write) |
| PreToolUse airbag | `PreToolUse`, matcher `write_to_file\|replace_file_content\|multi_replace_file_content` (the three documented AG write tools; path arg `TargetFile`) | snapshot-on-first-write, write-only; the answer is always `{"decision":"ask"}` |
| PostToolUse seatbelt | **moved to `PreInvocation`** (see limitation 2): PreToolUse enqueues the written path; the next PreInvocation diffs {airbag snapshot, disk} through the same `handleSeatbelt` and injects ONE `ephemeralMessage` on a structured-token drop | FYI advisory, never a block; cumulative-vs-baseline per write, CC cadence |

## Named limitations (honest scope — what this port does NOT do)

1. **No AG-native class-B discovery.** The gauge rides the existing Claude-Code discovery (`class-b.mjs`). On a machine **without** `~/.claude`, the platform detects as `unknown` → the gauge is INERT by construction (no entries, no state written, nothing created). On a CC-coexisting machine, an AG session gauges the **CC-load parcel** (CLAUDE.md walk + imports + CC memory dir) — honest overlap only where that walk imports the shared `AGENTS.md`/`MEMORY.md`; AG's own surfaces (`AGENTS.md` direct-load, `.agents/`, `~/.gemini/`) are NOT discovered. A real AG class-B adapter must land WITH the nested-scope 3-tier fix (same scope enum) and verified AG load semantics — deferred, not half-shipped.
2. **The seatbelt cannot ride AG's PostToolUse.** Per the v2.3.1 spec, PostToolUse input carries only `stepIdx` + `error` (no toolCall) and its output is ignored — there is neither a file path to check nor a channel to speak on. The sweep therefore runs at the NEXT PreInvocation (before the next model call — the same point in the loop where CC's PostToolUse stdout actually reaches the model). Residual gap: a drop written by the LAST write of a conversation, with no further model call, is detected only by the next conversation's… nothing — that final-write advisory is lost (the snapshot itself survives for manual restore).
3. **Spawn meter unwired (0o).** `invoke_subagent` is now a documented tool name, but no AG event carries a VERIFIED post-completion spawn signal: PreToolUse fires before approval (counting there over-counts denied spawns) and PostToolUse is nameless (attribution would trust the matcher blindly). Either guess would fabricate the true-bill numbers that justify the economic-dominance FULL force — numbers-shown must be TRUE, so the bill covers the main CC session only.
4. **Self-update nudge not ported.** Its payload (`claude plugin update`) is CC-plugin-specific; AG installs by file-copy (update = re-copy the plugin tree). `updateNudge:false` also keeps the shared throttle stamp unwritten from AG, so the CC-side nudge is never starved.
5. **`{"decision":"ask"}` is the neutral PreToolUse answer, not a no-op.** `decision` is REQUIRED; `ask` "respects Always-Allow" = AG's native gating, and the adapter never answers `allow` (a hook must not widen permissions) or `deny` (blocking a legitimate edit = sabotage). NAMED RISK: if AG treats a hook-returned `ask` as stricter than its default workspace-write policy, users may see extra permission prompts on governance-file writes — a live-validation check; if it bites, the fallback is unregistering PreToolUse (airbag off) in hooks.json.
6. **Delivery unvalidated.** Emissions follow the v2.3.1 spec; no claim that a live AG surfaces them (the 2026-07-16 inert-wire measurement — an older build — is why liveness is treated as OPEN until the canary passes). The write-path airbag file effects (snapshots under `<project>/.claude/coalwash/writeguard/`) are real regardless — filesystem effects, not injection-dependent. Validation runbook: `platform-configs/VALIDATION-AG.md`.

The writeguard needs NO discovery: it is basename-gated (`AGENTS.md`/`CLAUDE.md`/`MEMORY.md` anywhere in the home/project trees, plus `.md` under a `.claude` tree) — so AG edits to the shared governance files are guarded today.
