# CoalWash

CoalWash is a memory washer for agent memory. It cleans the fat of class-B memory and governance files, the always-loaded instructions and memory notes an agent reads every session, and it leaves the meat alone. Every removal goes through a fidelity gate, and every change is backed by an undo snapshot.

This README is a placeholder in the installed copy, written by the build from `plugin-src/README.md`. The full documentation, with the commands, the permissions and the benchmark, is the README at the repository root, which stays the source of truth until the documentation pass replaces this file.
